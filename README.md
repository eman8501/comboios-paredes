# Comboios de Paredes

Painel web responsivo para consultar chegadas e partidas na estação de Paredes.

## Objetivos
- Mostrar chegadas e partidas na estação de Paredes.
- Incluir Urbanos, Regionais, InterRegionais, Intercidades e outros serviços que parem na estação.
- Apresentar horários, origem, destino, linha, atrasos e supressões quando os dados estiverem disponíveis.
- Atualizar automaticamente a cada 30 segundos.

## Estado
Estrutura inicial do projeto. A integração com dados ferroviários em tempo real ainda necessita de validação. Não são apresentados horários fictícios como reais.
